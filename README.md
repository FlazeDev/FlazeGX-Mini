# FlazeGX Mini  
Controllers made for console are unnecessarily expensive or dont have enough features, so I made this custom OGX Mini so that i can use any controller with any console or even pc.  
  
## HARDWARE
It is a very simple project that uses only a waveshare rp2040 and a female usb a breakout board.  
I have also included a usb c to usb a adapter just to make it look nicer.
